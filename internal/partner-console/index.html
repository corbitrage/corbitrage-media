Partner Register Local prototype

Corbitrage Private Limited · internal compliance register for third-party and personal referral accounts.

Not a secure admin system. This is a local, single-browser prototype. It has no login, no server and no audit trail that can be trusted. It does not publish anything to the website, send data anywhere or activate any link. Do not enter PAN, bank, Aadhaar or customer data. Referral links are stored as host name only.
